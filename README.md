# MN Laser Lab Manager v39.3

Versione desktop professionale: React + FastAPI + SQLite + Electron + GitHub Releases.

Per lavorare bene:

1. Usa questo progetto come repository GitHub.
2. Compila localmente su Windows con `build_windows_desktop.bat`, oppure usa GitHub Actions.
3. Distribuisci all'utente finale solo il file setup `.exe`.
4. Pubblica nuove versioni tramite tag GitHub per abilitare gli aggiornamenti.

- `README_GITHUB_PROFESSIONALE.md`
